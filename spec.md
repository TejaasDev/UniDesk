# TAKUMI DELHI - Infinity Devs (Tejaas, Aksh and Homesh)

## UniDesk is a platform where users can enjoy prebuild/preconfigured web based operating system environments..

### Users will be able to create multiple instances of web based OS's from templates, prebuilt profiles.. the user will also be able to select custom collection of apps for profiles..

## DB connections

- a user can have multiple profiles
- a profile can have only one owner (user)

## UI

- The UI will be a mix of minimalism and neobrutalism..
- The layout will be simple, understandable and will showcase the core key features of the platform.
